微博内容工坊 · 使用说明
====================

这是一个在本地运行的演示站，可以按主题批量生成微博文案、话题和封面海报，也可以从公开热榜里选题。

重要说明
- 不需要登录微博，也请不要把账号密码填进这个站点。
- 「演示发布」只把记录写在这台电脑的浏览器里，不会真正发到微博。
- 第一次使用不需要任何密钥。默认用本地模板写文案，并在浏览器里画海报。
- 如果后面要接 DeepSeek（文案）或豆包（配图），再在页面「模型设置」里填写即可。密钥只存在本机浏览器，不要发给别人。

环境要求
- 先安装 Node.js（建议 20 或更高版本）：https://nodejs.org/

启动步骤
1. 解压这个压缩包。
2. 打开终端（Windows 可用 PowerShell），进入解压后的「微博内容工坊」文件夹。
3. 执行：

   npm install
   npm run dev

4. 用浏览器打开：http://127.0.0.1:4317

基本用法
1. 选一个示例主题，或自己写主题；需要的话勾选热榜再点「用所选热点填入主题」。
2. 选择条数（1–12），点「批量生成」。
3. 每条都可以改文案和话题，也可以重新生成、下载配图、复制文案。
4. 「导出全部」会下载一个包含全部文案和配图的压缩包。

更完整的说明见同目录下的 README.md。
